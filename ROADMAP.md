# Roadmap

## Now

- Keep the core auditor dependency-free and deterministic.
- Expand anonymized regression fixtures from real Mealie failures.
- Document read-after-write and exact-filter adapter contracts.

## Next

- Reference REST adapter generated from a target instance's OpenAPI schema.
- Optional MCP adapter with the same pre-save gates.
- Meal-plan and shopping-list reconciliation reports.
- Machine-readable SARIF output for CI annotations.

## Later

- Community-maintained multilingual alias packs.
- Compatibility matrix across supported Mealie releases.
- Reusable browser-level conformance suite for adapters.

Votes and scoped pull requests are welcome. Open an issue before large changes.
